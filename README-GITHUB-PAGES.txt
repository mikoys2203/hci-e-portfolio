RAZZIE HCI ePortfolio - GitHub Pages deployment

1. Open GitHub Desktop -> hci-e-portfolio -> Show in Explorer.
2. Extract THIS zip. Copy the CONTENTS into your repository folder, not the zip itself.
3. Confirm index.html, assets/, docs/, and .nojekyll are in the repository root.
4. GitHub Desktop -> Summary: Add RAZZIE ePortfolio website -> Commit to main.
5. Click Push origin (or Publish repository if necessary).
6. On GitHub website -> repository Settings -> Pages.
7. Under Build and deployment, Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
8. Visit the link shown on the Pages screen after deployment. It is normally:
   https://YOUR-GITHUB-USERNAME.github.io/hci-e-portfolio/

Site pages use hash navigation (e.g., #midterm) and the document links are relative.
Do not commit the ZIP itself. PDF files are PUBLIC if the repository/site is public.
Review personal data and photos before publishing.
